# Sahi Park

A smart parking space management platform connecting parking space providers with renters.

## Features

- **For Renters**: Search, view, and book nearby parking spaces
- **For Providers**: List parking spaces and earn money
- **Admin Panel**: Manage users and parking spaces
- **Real-time Availability**: Live parking space updates
- **Secure Authentication**: Separate login for renters and providers

## Tech Stack

- **Frontend**: React.js
- **Backend**: Node.js/Express
- **Database**: MongoDB

## Getting Started

### Prerequisites

- Node.js installed
- MongoDB running

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm start
   ```
